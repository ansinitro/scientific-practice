# Итоговый отчёт: исследование STT-моделей для казахской речи

**Дата:** 2026-05-19  
**Исполнитель:** [Твоё имя]  
**Задача:** Сформировать пул открытых моделей автоматического распознавания речи (STT/ASR) с поддержкой казахского языка (multilingual / bilingual ru‑kk). Минимум 3‑4 модели. На текущем этапе бенчмаркинг не требуется.

---

## 1. Требования

- Приоритет – **multilingual‑модели** с подтверждённым казахским.
- Допускаются **bilingual ru‑kk**.
- Kazakh‑only модели **исключаются**.
- Модели должны быть **открытыми** (доступны веса, разрешительная лицензия).
- Платформенные API‑решения без публичных весов не принимаются.

---

## 2. Методология

**Источники:** Hugging Face Hub, GitHub, ModelScope, Papers with Code, arxiv.org.

**Процесс валидации:**

1. Поиск по ключевым словам: `kazakh`, `kk`, `ru‑kk`, `multilingual ASR`.
2. Проверка model card / README на наличие явного упоминания казахского (`kaz`, `kk`).
3. Проверка лицензии и доступности весов (через transformers, NeMo, ESPnet, ONNX).
4. Исключение при:
   - отсутствии подтверждённого казахского;
   - закрытых весах / только API;
   - утрате multilingual‑свойств после дообучения (Kazakh‑only).

Все данные верифицированы по официальной документации (model cards, статьи, репозитории).

- Для **чистого, точного распознавания казахской речи** – FastConformer (абсолютный лидер по доказанной точности).

- Обе модели открыты и дополняют друг друга, поэтому обе включены в основной пул.

## 6. Анализ репозиториев ISSAI

ISSAI (Институт умных систем и искусственного интеллекта, Назарбаев Университет) – ведущий разработчик речевых технологий для казахского языка.

**Ключевые находки в их GitHub (github.com/IS2AI):**

- **Soyle** (1⭐, но основной сайт проекта) – флагманская мультиязычная ASR.
- **TurkicASR** (11⭐) – модель для 10 тюркских языков (Conformer, 108.68M).
- **MultilingualASR** (14⭐) – ESPnet Transformer (2021), kk/ru/en, WER 20.5% – академический бейзлайн.
- **Kazakh_ASR / ISSAI_SAIDA** – датасеты и рецепты для KSC2, но модели там kk‑only.
- **CLTL_Turkic_ASR** – transfer learning **с казахского на другие** тюркские языки, не ASR для казахского.

**Вывод:** ISSAI подтверждает статус основного центра компетенций по казахской речи. Их модели Soyle и TurkicASR напрямую использованы в нашем пуле.
