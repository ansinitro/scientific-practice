# Открытые TTS-модели для казахского языка

**Полное исследование моделей, датасетов и методов обучения**

**Дата:** 2026-05-26  
**Исполнитель:** Аңсар Шаумен  
**Цель:** Систематизировать все доступные открытые решения для синтеза казахской речи (TTS), описать архитектуры, датасеты и лучшие практики.

---

## 1. Введение

Ментор поставил задачу:

- Изучить **все существующие открытые TTS‑модели** с поддержкой казахского языка.
- Понять, **как проходило обучение**, какие архитектуры использованы.
- Определить **использованные датасеты** и их характеристики.
- Взять за ориентир лучшую русскоязычную модель (`F5‑TTS_RUSSIAN`) и оценить возможность адаптации на казахский.

В результате исследования выявлено **8 открытых моделей**, **4 основных речевых датасета** и **4 архитектурных семейства**. Ключевым центром разработки является **ISSAI (Назарбаев Университет)**, выпустивший 4 из 8 решений.

## 4. Архитектуры и методы обучения

### 4.1. Tacotron 2 + вокодер (ESPnet‑пайплайн)

Используется в **KazakhTTS, KazakhTTS2, TurkicTTS**.

- Кодировщик: двунаправленная LSTM (512 юнитов), вход – 42 буквы казахского алфавита + 5 спецсимволов.
- Декодер: 2‑слойная LSTM (1024 юнита) с attention.
- Вокодер: WaveGlow (v1) → HiFi‑GAN (v2).
- Оптимизатор: Adam, lr=10⁻³.
- Обучение: отдельные чекпоинты для каждого диктора.
- Оборудование: NVIDIA V100 на DGX‑2.

**Особенность TurkicTTS:** IPA‑транслитерация — буквы других тюркских языков переводятся в казахский алфавит, что позволяет использовать единую акустическую модель.

### 4.2. VITS (End‑to‑End)

**MMS‑TTS Kazakh, Piper TTS.**

- Условный VAE + нормализующие потоки + декодер HiFi‑GAN + стохастический предсказатель длительности.
- Не требуется отдельный вокодер — модель выдаёт waveform напрямую.
- Детерминированность достигается фиксированным seed.
- Для MMS‑TTS тренируется отдельный чекпоинт на каждый язык (1107 языков).
- Piper экспортирует модели в ONNX для запуска на Raspberry Pi.

### 4.3. Диффузионные модели (GradTTS, F5‑TTS)

**KazEmoTTS:** GradTTS с жёсткими метками эмоций. Диффузионный вероятностный процесс, 3.7M шагов обучения, Adam. Управление эмоциями через classifier guidance.

**F5‑TTS / Tote‑TTS:** DiT (Diffusion Transformer) с ConvNeXt V2. Flow matching вместо score matching.

- Zero‑shot клонирование голоса по референсной записи (5‑30 сек).
- Тонкая настройка возможна на одном дикторе — Tote‑TTS обучен на подмножестве KSC2 (4.8 ГБ).
- Быстрый инференс, лучшее качество клонирования, чем у VITS.

### 4.4. GPT + Flow Matching (IndexTTS2)

**IndexTTS2‑Kazakh:**

- Текст → семантические токены через GPT‑модель (дообучена на казахском BPE‑словаре 2000 токенов).
- Flow matching для генерации спектрограмм.
- Семантический энкодер: Qwen 0.6B.
- Обучение: 3 эпохи, 912 шагов на Google Colab A100 40GB.
- Ограничение: модель одного диктора, не обобщается на другие голоса.

## 5. Лучшая практика: F5‑TTS Russian и адаптация на казахский

Ментор рекомендовал модель [F5‑TTS_RUSSIAN](https://huggingface.co/Misha24-10/F5-TTS_RUSSIAN) как эталонную русскоязычную TTS.

**Ключевые характеристики:**

- Архитектура: Diffusion Transformer (DiT) + ConvNeXt V2 + Flow Matching.
- Zero‑shot клонирование: достаточно 5‑секундного образца голоса.
- Может быть тонко настроена на любой язык при наличии аудиоданных.

**Адаптация к казахскому уже выполнена:**  
Проект **Tote‑TTS** — это именно F5‑TTS, дообученный на казахском (и арабском). Доступен на [GitHub](https://github.com/mamyrbekparakhat/Tote-TTS). Поддерживает zero‑shot клонирование.

**Вывод:** F5‑TTS является лучшей открытой архитектурой для синтеза голоса на русском и казахском языках в 2025 году. Для промышленного использования рекомендуется дообучить модель на полном KazakhTTS2 (271 ч) с несколькими дикторами.

## 6. Сравнительный анализ и ключевые выводы

| Критерий                   | Лучшее решение     | Обоснование                               |
| -------------------------- | ------------------ | ----------------------------------------- |
| **Качество речи (MOS)**    | KazakhTTS2         | MOS 3.6–4.2, лучший среди открытых КК TTS |
| **Эмоциональность**        | KazEmoTTS          | Единственная модель с 6 эмоциями          |
| **Многоязычность**         | TurkicTTS          | 10 тюркских языков                        |
| **Лёгкость / Edge**        | Piper TTS          | 5 голосов, работает на Raspberry Pi       |
| **Клонирование голоса**    | F5‑TTS (Tote‑TTS)  | Zero‑shot, 5 сек образца                  |
| **Простота использования** | MMS‑TTS Kazakh     | Готовый pipeline Transformers             |
| **Современный подход**     | F5‑TTS / IndexTTS2 | Flow matching, DiT, GPT‑based             |

**Важные факты:**

1. **ISSAI — основной центр компетенций** (4 из 8 моделей).
2. **Все открытые датасеты — CC BY 4.0**, что разрешает коммерческое использование.
3. **Тренд 2024–2025:** Flow matching / Diffusion‑Transformer вытесняет Tacotron 2 и VITS в задачах клонирования голоса.
4. **Главная нехватка:** специализированных TTS‑данных >300 часов. KSC2 (1200 ч) частично закрывает пробел, но структурирован для ASR, а не TTS.

---

## 7. Рекомендации

1. **Для быстрого прототипа** — MMS‑TTS Kazakh (одна строка в Transformers).
2. **Для максимального качества речи** — дообучить F5‑TTS (Tote‑TTS) на KazakhTTS2 (271 ч) с несколькими дикторами.
3. **Для эмоционального синтеза** — использовать KazEmoTTS (GradTTS) и одноимённый датасет.
4. **Для edge‑устройств** — Piper TTS (5 голосов, ONNX).
5. **Для тюркской многоязычности** — TurkicTTS (IPA‑транслитерация).
